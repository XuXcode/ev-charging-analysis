# P0 实施与运行核验（2026-10-04）

本轮保留 Vue3、FastAPI 和 MySQL 架构，独立增加复核台账、官方统计和道路观测模块。站点仍由现有真实 API 提供，没有引入模拟分析结果。

## 数据核验

- 入库高德 POI 样本 12,601 条，公共候选 11,720 条；这些数值不表示官方设施总量或已经核验的营业设施。
- 对原先 49 条行政几何异常逐条调用高德逆地理编码：49 条均支持原始行政编码。异常来自旧版简化展示边界，不能据此修改站点编码。
- 核验并安装统一 122 区县高德边界后，全部入库样本的几何归属错配 49 → 0，边界外 1 → 0，多区县命中 0 → 0。未修改站点坐标和行政编码。
- 保存 244 份边界版本、446 条复核事件；疑似停业/拆除 139、专用 184、个人 25，共 348 条进入需继续复核状态。这里只记录复核任务，不宣称已经证明停业、拆除或对外服务情况。
- 新边界下 48 个类别、状态和复核线索组合快照已重新计算，历史版本保留。质量变化详见 `POI_REVIEW_P0.md`、`BOUNDARY_REVIEW_APPLIED.json`、`P0_DATABASE_AUDIT.json`。

## 官方统计

独立 `official_statistics` 表、迁移、官方来源校验、幂等导入、读取接口和前端入口已完成。每条记录保存来源、链接、年份、单位、统计口径、更新时间及文件/行号证据。目前真实官方记录为 **0**，因此相关指标继续显示“—”。POI 样本不能填入官方统计表冒充设施总量。导入方式见 `PUBLIC_STATISTICS.md`。

## 道路可达性结果

122 个区县各取一个内部代表点，对 20km 内按空间距离排序的最近 3 个公共候选站点查询驾车路线；366 个候选关联合并为 364 个唯一 OD。

| 时间阈值 | 满足阈值的完整代表点 | 等权代表点比例 |
| -------- | -------------------- | -------------- |
| 5分钟    | 25 / 122             | 20.49%         |
| 10分钟   | 58 / 122             | 47.54%         |
| 15分钟   | 83 / 122             | 68.03%         |

平均候选最短驾车时间 13.39 分钟，其对应路线平均距离 7.20km。不能解释为人口、面积或整个区县的服务覆盖，也不能保证空间最近的三站中包含道路时间全局最近站。

道路首轮成功请求 364 次，加上此前网络失败但保守计入额度的 81 次预留，共 **445 / 500**。实际复跑命中 364 条 OD 缓存，新增路线调用 0 次，结果一致。行政核验的 49 次逆地理编码和 122 次边界请求单独记录，不计入道路路径规划额度。

支持限速、重试、额度预留、失败停止、任务续跑、OD缓存、冻结输入、版本和批次追溯。新边界核验确认原道路任务的 122 个代表点仍全部位于对应区县，无需修改历史任务或追加路线调用。详见 `ROAD_ACCESSIBILITY.md`、`ROAD_ACCESSIBILITY_RESULT.json`。

## 前端和地图交互

- 统一市州 → 区县级联选择，动态读取区县目录；地图、筛选、排名和 URL 同步，刷新保留行政范围。
- 全省 ECharts 专题地图、市州/区县高德真实站点地图分别保留，支持全省/市州/区县返回。
- 市州地图支持 Marker、聚合、等权 POI 热力、区县边界、真实站点检索与信息窗。
- 道路专题接入保存的真实观测，支持 5/10/15 分钟、代表点比例、候选最短时间、对应道路距离、区县排行、分级设色、累计曲线、Tooltip、完整性警告与追溯。
- 市州地图和市州道路模块入口进入真实道路专题，并保留当前市州/区县和筛选条件。未计算口径仍显示待接入，不回退冒用其他结果。

## 交互性能和实测

`moveend`、`zoomend` 共用 450ms 防抖，仅在视野模式请求 bbox。站点加载支持取消和旧响应拒绝；同一行政范围的视野请求在新结果返回前保留现有点位。加载状态不再触发图层重绘；同图层聚合使用 `setData`，热力使用 `setDataSet`，复用已有实例。区域变更清理过期点位，地图事件和 ResizeObserver 在卸载时释放；相同范围返回保留视角。

浏览器实测全省排行 → 长沙 → 级联芙蓉区 → 高德地图 → 道路专题；Marker/热力/聚合切换，连续拖动、连续缩放，开福区 → 天心区切换，页面刷新范围恢复，15分钟切换和返回全省均正常。连续操作后站点接口日志响应约 15–27ms；这是本机当次接口耗时，不是帧率或性能改善百分比。未进行标准化 GPU/FPS 压测，不能承诺所有设备持续60FPS。代表点结果截图见 `screenshots/p0-road-county-15min.png`。

## 限制及下一阶段

17 个区县存在检索完整性警告；高风险营业状态仍需人工或可信运营证据复核。行政区边界为供应方商业地图版本，不作为法定勘界依据。道路采样是每区县一个代表点的首轮验证，并非等时圈；路线是查询时供应方结果，缓存有效期与参数均有记录。

优先补充可核验的官方统计和高风险复核证据，再明确下一轮额度与采样规模，扩展规则网格/真实需求点并评估候选筛选误差。本轮未实现供需指数、风险评级、OR-Tools、AI 或权限系统。
