## 筛选、版本与缺失

新模块通过独立只读API适配器读取真实接口，不接入项目的离线演示回退。用现有metadata.filters验证分类、核验、待复核及批次；网格/LISA指定同一个snapshotId并验证返回版本。单证据批次等价匹配仅接受现有后端允许的datasetQualityRunIds单值情况。

治理记录是当前查询计数，可能与历史冻结快照存在时间差，不合并为同一时点总量。每张图带独立source、filters和版本/任务信息；治理导出用参数记录observedAt，不冒用空间快照版本。质量计数按分类/状态逐组合请求，最多3个并发，请求失败不按零补齐，筛选变化会取消旧请求并丢弃迟到结果。

网格筛选沿用现有接口：保留与行政区相交的完整固定网格，不重新裁切或重分配边界样本。因此城市范围内网格样本和按adcode的城市计数不一定一致。范围内LISA只汇总这些网格已有统计分类，不引用全省Moran's I推断局部显著性。

道路接口不支持非公共候选、额外人工状态、线索或指定批次时，图表显示该筛选无对应观测，绝不偷偷回退公共候选。自定义地点OD缓存不进入122区县道路统计。整个页面只读现有MySQL接口，不访问高德、不执行采集、统计或付费请求。

## 工程边界

不新增后端接口、数据库变更、测试文件或测试依赖。前端只进行展示用计数、分组及累计比例。ChartContainer新增饼图注册和洞察分类点击事件；双轴导出使用对应序列的单位，保留既有图表默认行为。四个原页面不变，地图性能代码不变。
