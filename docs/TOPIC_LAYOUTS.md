# 专题页面信息结构

本轮只调整已有 Vue 页面和地图展示组件。真实站点采集、FastAPI 路由、数据库和空间分析计算均未修改；已有分析快照通过原 `/analysis/latest`、边界与图层接口读取。

| 页面     | 主视觉                     | 辅助内容与交互                                                                     |
| -------- | -------------------------- | ---------------------------------------------------------------------------------- |
| 全省总览 | 湖南省14市州专题地图       | 核心指标、样本排名与区域差异，仍沿用总览结构                                       |
| 空间格局 | 地图 + 右侧分析面板        | 行政区、网格与聚集图层；选择市州显示区县分布；点击区县定位                         |
| 可达性   | 1km覆盖地图 + 独立覆盖指标 | 真实快照的覆盖率、未覆盖面积、区县累计分布与低覆盖排行；5/10/15分钟单独显示待接入  |
| 供需协调 | 供给 × 需求四象限容器      | 供需口径说明、区域定位小地图；没有可靠输入，不绘制分析点位                         |
| 市州差异 | 14市州指标排行             | 数量/密度/覆盖率切换；密度—覆盖散点图；辅助地图联动；箱线摘要和历史统计保留入口    |
| 薄弱区域 | 区县未覆盖清单             | 按覆盖率升序；覆盖率、未覆盖面积、待复核线索；点击清单定位区县；风险等级保持未评级 |
| 布局优化 | 现状覆盖 vs 方案结果       | 双栏对照容器；覆盖变化、新增点位和收益待接入；未运行选址算法                       |

## 组件边界

- `AnalysisView.vue` 按既有专题路由组织不同信息层级，不复制首页 KPI 布局。
- `MapView.vue` 统一入口增加 `parentCode`、`initialLayer`、`focusCode` 与区县选择事件；原市州高德地图入口不变。
- `SpatialMap.vue` 使用既有 GeoJSON 和分析图层，按选择区域定位并高亮；点击全省总览仍进入原市州路由。
- `ChartContainer.vue` 增加 ECharts 散点图注册，沿用原有鼠标与城市代码联动。
- `utils/analysis-charts.js` 仅组织真实快照的图表格式、排序和累计比例，不新增空间算法或估算业务统计。

区县累计分布使用区县等权比例，不代表面积加权覆盖率。1km覆盖为模型直线几何样本覆盖，非道路可达性；样本未覆盖不等于实际没有设施。星号表示检索触及上限，样本可能不完整。具体公式和限制见 [SPATIAL_METHODS.md](SPATIAL_METHODS.md)。

## 验证

逐一打开七个菜单页面，检查专题主视觉与信息结构。重点检查市州差异指标切换和地图高亮、空间格局市州/区县切换、缺口清单区县定位、分钟可达性待接入状态，以及1920×1080、1366×768桌面显示。截图保存在 `docs/screenshots/topic-*-updated.png`。

生产验证命令：`npm run build`。Ant Design Vue 与 ECharts 仍有超过500KB的分块体积提示，属于构建警告，不是构建失败。
