两条记录统计时点均为对应年末，按“万个×10000”换算，原文精度保留在scope_description中。它们是独立来源的历史省级背景，不是2026年实绩，也不是公共桩总量、站点数、充电枪数量或站点服务能力。

## 同年数值差异

- 2023年：项目已有省工信厅材料244400个；新核对省发改委材料227300个。
- 2024年：项目已有湖南日报会议报道384000个（public）；新核对官方政策解读421500个（official）。

尚未核实差异源于统计范围、修订、时点还是其他原因。保留全部记录和来源类别，不取平均、不覆盖旧值、不把发布更晚自动等同于可比统计。不得用上述记录拼接同比曲线，也不得与异年新能源汽车保有量或POI样本计算车桩比。

“公共快充桩”是子项，不替代所有公共桩；政策中的2025年建设目标不作为已建实绩。[国家能源局2025年7月发布说明](https://www.nea.gov.cn/20250731/9c2d1f4c046c4b25ac6f8882a7ffb01e/c.html)指出统计体系进行了调整并使用充电枪口径；全国值未写入湖南统计库，历史桩口径不能直接与枪口径拼接。

## 页面与报告

数据质量抽屉的统计面板增加“核对同年来源”。从既有官方/公开读取接口分别查询，同地域、年、指标、单位分组；不同数值只作为来源核对线索，不证明这些记录统计范围相同。原文链接和口径逐条展示。

每类来源最多核对前100条，超过时提示部分核对，避免把分页结果当完整审计。切换市州/区县或指标时取消旧请求并清除结果，市州缺失数据不借用全省数值。

证据报告版本为evidence-report-v3：增加statisticsDifferences与有来源哈希的差异事实。报告仍由确定性代码生成，不引入AI、不修改计算数值；已有报告留存不覆盖。导出检查当前内容哈希，来源更新后旧预览不能导出为“同一证据”。
