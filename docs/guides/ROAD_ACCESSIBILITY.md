# 真实道路可达性 P0

本模块独立于 `sample-spatial-v1.2` 的1km直线缓冲。算法版本 `road-county-representative-v1`：每区县真实边界取一个内部代表点，先STRtree包围盒筛选，再按球面距离20km内选最近3个公共候选POI。允许跨行政边界找站，不能把行政编码约束当成通行壁垒。

道路时间和距离来自高德v3驾车API，strategy=0、GCJ-02坐标、六位小数。返回秒和米，不按固定车速转换。一个起点必须完成全部候选OD后才纳入阈值比例分母；无候选、失败、未执行为未知。平均时间/距离仅使用存在有效路线且候选查询完整的起点，距离属于最短候选时间对应路线。阈值比例是**区县代表点等权可达比例**，不是省域面积、人口覆盖或道路等时圈，不能推论整个区县都能在该分钟内到达。

`road_accessibility_runs`冻结起点、候选站点、边界哈希、质量批次、OD参数、任务进度及观测时间。MySQL JSON浮点重新序列化时数值哈希按8位小数规范化，不能用裸浮点JSON比较伪报篡改；API请求坐标固定6位。`road_od_cache`按有方向起终点、策略、API版本及坐标系哈希，TTL7天，仅缓存有效路线或供应方明确无路线。

调用前提交额度预占，进程中断也不清零；缓存命中不计调用。每OD最多3次尝试，间隔至少1秒，失败递增退避；连续3次传输失败熔断，Key/额度错误停止。数据库隔离的MySQL advisory lock防止同库并发执行。额度是每冻结任务参数，不能靠断点重启重置；多任务总预算需要人工/调度层统筹，本轮总预算500次。

```powershell
cd backend
.\.conda\python.exe -m alembic upgrade head
.\.conda\python.exe -m app.services.analysis.road --prepare-only --max-calls 500
# 确认冻结任务ID后，执行或恢复同一任务
.\.conda\python.exe -m app.services.analysis.road --run-id TASK_ID
```

读取 `GET /api/v1/analysis/accessibility/latest`，支持city_code/adcode且不会触发道路请求。查询先选ID，再投影结果字段，避免大型冻结JSON排序造成MySQL sort memory不足。不返回冻结原始站点输入。接口当前只读取公共候选冻结结果，其他治理筛选明确404，不回退。前端支持5/10/15分钟、专题设色、累计曲线、区县排行、完整性警告及计算追溯；阈值通过travel_time写入URL，并保留市州/区县选择上下文；本轮工程整理未执行浏览器功能验证。
