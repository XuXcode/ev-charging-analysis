# 四页信息结构

| 页面       | 主视觉                                 | 分析目标                           |
| ---------- | -------------------------------------- | ---------------------------------- |
| 全省总览   | 湖南14市州专题地图、排名               | POI样本总体分布及区域差异          |
| 空间格局   | 专题地图与空间统计面板                 | 密度、5km网格、1km直线样本覆盖     |
| 可达性分析 | 代表点道路地图、累计曲线和低可达性清单 | 122区县代表点5/10/15分钟道路观测   |
| 市州差异   | 市州对比、区县分布和区域分型           | 同一口径的真实数量、密度和覆盖差异 |

省→市州→区县→站点钻取、全库搜索、筛选、质量追溯及PNG/CSV/快照导出共用真实API。区县选择进入高德实景地图。区域分型基于真实密度与直线覆盖中位数，不解释为需求或供需。

POI样本不等于官方设施总量；直线覆盖不等于道路、人口覆盖；区县代表点道路结果不等于区县整体覆盖。缺失观测单列。

## 全屏地图工作台

地图渲染层覆盖浏览器视口，顶部工具栏、左右侧栏浮于地图之上。地图按当前真实行政边界的宽高比适配可用区域，面板折叠后仅调整布局，不重建地图实例。市州与区县实景地图保留高德署名及坐标口径。

- 全省总览：14市州专题地图为主，右侧呈现核心指标与完整排名，采集质量详情按需展开。
- 空间格局：数量、密度、网格与直线样本覆盖共用地图画布，右侧呈现区县分布和覆盖累计曲线。
- 可达性：道路时间专题地图配合阈值切换、观测指标和低可达性清单；选择区县切换真实站点地图，可返回道路专题。
- 市州差异：中央工作区以对比图为主，右侧小地图和散点图辅助联动，不复用总览指标卡布局。

左右面板独立折叠；纯地图模式隐藏分析面板与筛选，Esc返回。玻璃模糊只用于外层面板，内部数据区采用轻量底色；系统请求减少透明度或浏览器不支持模糊时回退为可读的实色背景。

规划参考、需求代理评分与选址优化不属于正式页面。历史数据库迁移保留，未提供对应业务接口。
