# 第一版POI样本空间分析

> 本文的 v1.1 数量和结果为历史批次验收。2026-10-04 补采后的 v1.2 模型、同输入对照和当前结果见 [DEEP_OPTIMIZATION.md](../history/DEEP_OPTIMIZATION.md)；不得将下文10,745条或6.3670%当作最新结果。

## 输入与可追溯性

数据来自既有高德采集批次 `77751da1e930432394ebe8325068c3b6`，全部10,745条保留POI参与计算。它们包含公共候选、专用、个人、疑似停业与未知类别；分析不能解释为当前营业公共充电设施总量或官方覆盖率。

使用14市州、122区县真实边界。121区县取自DataV，祁阳市现行编码431181单独读取高德行政边界，来源、内容哈希与本地读取/入库时间随快照记录；该时间不是上游边界发布日期。4个无效面几何经GEOS `make_valid` 修复并提取面部分；原始几何仍保留，快照记录修复方法、修复前后模型面积和面积变化。

分析快照记录批次、站点与质量字段指纹、区县完整性指纹、边界哈希、算法版本、源代码哈希、依赖版本、计算时间和参数。当前算法为`sample-spatial-v1.1`，治理规则为`poi-evidence-v1.1`，已核验快照为`c03b72e46fa64bb1ab7a3c3416ad45fe`。相同输入和参数重复执行复用快照；`--force`可生成独立快照。读取接口不运行空间算法。

## 坐标和面积口径

原始点与边界为GCJ-02。使用以111.5°E、27.5°N为中心的局部LAEA坐标图模型获得米制近似；WGS84椭球参数只作为尺度模型，不意味着输入已经转换到WGS84。未进行官方基准转换或实地校准，面积与1km距离具有模型近似性，不能用于精密测绘或官方统计。

Shapely要求几何位于同一平面，缓冲与面积不能直接在经纬度角度上计算，见[Shapely坐标系说明](https://shapely.readthedocs.io/en/stable/manual.html#coordinate-systems)。模型转换由[pyproj Transformer](https://pyproj4.github.io/pyproj/stable/api/transformer.html)执行，完整pipeline持久化在快照参数中。

## 计算公式

- 行政区POI样本数 `N_r`：按供应方原始 `adcode` 计数，不自动改址。
- 占全省样本比例：`N_r / N_省 × 100%`。
- 边界模型面积 `A_r`：修复后的投影面面积，单位km²，非官方统计面积。
- POI样本密度：`N_r / A_r`，单位条/km²。
- 1km样本缓冲并集 `U`：所有保留样本点在模型平面上建立半径1,000m的缓冲区，圆用96条边近似，先合并，避免重叠重复计数。
- 区域样本覆盖面积：`Area(B_r ∩ U)`，包含邻近行政区样本对边界内的直线覆盖。
- 1km样本覆盖率：`Area(B_r ∩ U) / Area(B_r) × 100%`。
- 样本未覆盖面：`B_r − U`；未覆盖面积为其模型面积。
- 网格：固定米制原点、5,000m边长，将方格裁切到市州边界并集；网格密度用裁切面积作分母。点在省级几何外不塞入网格，另行记录。
- 聚集分布：有样本网格密度的P95作为描述性阈值，达到阈值标为聚集网格；并列可能使数量超过5%。这是分布描述，不是Gi*、显著性检验或道路服务热点。

覆盖图层与未覆盖图层仅为传输展示做25m拓扑保留简化；面积指标在简化前计算。网格图层未做简化。

网格计数必须与省级几何内样本数守恒，否则任务停止保存。按市州/区县查询网格时返回与范围相交的完整省级固定网格，不重新计算区县局部网格密度；边界格可能包含邻近区域样本。

## 运行与接口

```powershell
cd backend
.\.conda\python.exe -m app.services.governance_job
.\.conda\python.exe -m app.services.boundary_job
.\.conda\python.exe -m app.services.analysis.job
# 可选：相同输入也生成新快照
.\.conda\python.exe -m app.services.analysis.job --force
# 只读运行审计，不采集或修改站点
.\.conda\python.exe -m app.services.analysis.audit --output ../docs/RUNTIME_AUDIT.json
```

- `GET /api/v1/analysis/latest`：小体量快照信息、指标口径和市州/区县结果，不返回全部几何图层。站点数量、更新时间、坐标/归属/质量字段指纹、区县完整性指纹、边界哈希或算法版本变化时标记过期。
- `GET /api/v1/analysis/boundaries?parent=430000`：14市州边界；parent为市州编码时返回其区县边界。
- `GET /api/v1/analysis/layers/{grid|hotspots|coverage|uncovered}`：支持snapshot_id固定版本以及city/adcode/bbox范围筛选。
- `GET /api/v1/quality/pois`：原复核清单、类别、状态、行政区与名称筛选。`all_records=true`可查看全部保留记录。

## 限制与扩展

检索未触及上限也不代表供应方收录完整；17个触及上限区县及所属市州带完整性警告。样本覆盖只表示几何范围，未扣除山地、水域或人口空间，未验证设施营业、容量和公共开放，也不代表人口覆盖率。风险等级、道路可达性、供需指数、选址优化与AI均未计算。

几何服务与任务持久化分离，后续GeoPandas或其他分析实现可在相同批次/参数/版本协议下新增算法，不覆盖历史快照。正式坐标校准、公共开放复核与可靠统计口径应优先于扩展业务结论。

可靠统计独立导入，来源、年份与口径不混入POI样本指标，见[公开统计导入说明](PUBLIC_STATISTICS.md)。当前完成核验、实测耗时及限制见[完成审计](../history/COMPLETION_AUDIT.md)。
