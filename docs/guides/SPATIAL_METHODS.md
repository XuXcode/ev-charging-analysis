# 空间分析方法

## 样本与行政范围

分析输入为数据库中真实高德可检索充电设施POI，默认公共候选分类，按市州、区县、类别、复核状态及来源批次筛选。样本数量不代表官方设施总量或已确认营业数量；不同筛选结果不混用。

边界采用真实湖南14市州和122区县GeoJSON，记录边界版本与哈希。站点原始GCJ-02坐标保留；边界匹配与修订有独立证据，不覆盖原始POI。

## 密度与网格

密度为样本数÷行政区模型面积×100，单位条/100km²。5km网格描述分布，按边界裁切并记录归属；热点采用有样本网格密度P95阈值，仅是描述性分布，不是统计显著性或需求热点。

## 1km直线样本覆盖

对样本点创建模型半径1000m缓冲区，合并后与行政区边界相交。覆盖率为交集面积÷模型行政区面积；未覆盖区域为边界与合并缓冲区的差集。仅描述样本的几何面积范围，不代表道路时间、人口覆盖、服务能力或实际营业。

GCJ-02坐标图采用湖南区域LAEA米制近似；未宣称GCJ-02为WGS84，也没有官方基准转换或实地校准。投影、面积偏差、网格计数、归属和无效几何处理记录于快照metadata及空间审计材料。

## 快照与追溯

app/services/analysis/job.py、scope_job.py独立计算派生结果，保存版本、参数、来源、输入指纹、冻结输入和边界哈希。页面只读取已生成快照；无匹配结果明确缺失，不自动替换为其他筛选范围，不在GET中执行缓冲计算。

道路分析另见[代表点道路方法](ROAD_ACCESSIBILITY.md)，质量口径见[POI质量](POI_QUALITY.md)，接口见[API契约](API_CONTRACT.md)。当前数量、时间和有效范围以实时接口或冻结快照为准，不固定沿用历史开发阶段数值。
