# 区县站点地图交互

2026-10-04，基于现有前端增量修改，未修改 FastAPI、采集模块或数据库。

- 未选择区县时仍使用原有省/市州专题地图。通过统一筛选、专题地图或区县排行选择区县后，MapView 切换高德 JS API 2.0，按市州 + 区县 + 当前类别/复核/批次读取现有 `/stations` 接口。
- “返回专题地图”清除区县选择，保留市州、类别、复核、批次和指标。站点地图“1km样本覆盖”读取已有区县覆盖快照，可以“返回高德站点”；缺失快照显示待接入，不产生模拟覆盖结果。
- 市州详情下方的专题结果保留 ECharts 图层，避免同时创建两个高德地图。区县目录与当前统计快照分离，目录可以用于选择，旧目录中的指标不得作为缺失筛选快照的结果。
- 搜索已升级为后端全库搜索，支持名称、地址和 POI ID，每页8条候选，可叠加分类/复核/批次与行政区筛选，350ms防抖和过期请求取消。点击或回车定位并打开来源信息窗；跨行政区结果进入相应市州/区县。当前视野模式中的显式搜索定位允许移动地图并重新加载新bbox。
- 信息窗定位按[高德地图状态说明](https://developer.amap.com/api/javascript-api-v2/guide/map/state)使用即时相机定位，避免缩放过渡中信息窗落到视野外。区县悬停不覆盖已选站点信息；点击空白地图可取消选中。
- 可达性地图补充区县选择联动。薄弱区域清单选择区县后保留当前市州其他条目，并自动展开高德地图容器，避免小地图裁掉工具栏与地图。

浏览器实测：长沙市→芙蓉区179条；搜索“特斯拉”4条，点击后来源信息窗位于地图内；切换1km覆盖及返回专题地图；可达性排行选择绥宁县23条。13项前端测试验证无效区县、目录归属、搜索范围/候选上限及既有筛选行为。生产构建通过，仍保留原有 ECharts 共享块体积提示。

道路分钟可达性、可靠供需、风险评级和布局优化仍等待可靠输入，不属于本次交互补齐范围。
