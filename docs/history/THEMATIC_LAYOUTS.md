## 统一上下文

`fortend/src/stores/analysis.js`管理市州、区县、POI分类、复核状态、批次和指标。`AnalysisFilter`提供筛选与恢复默认；`useAnalysisContext`同步URL。地图、排名、比较图共用指标；区县范围联动清单、覆盖分布与地图定位。市州差异保留14市州的可比较背景，以选中状态强调当前市州。

分类 / 状态 / 批次读取对应持久化快照。没有匹配快照时显示待接入，禁止回退到未筛选结果。市州站点请求传递相同分类、状态和批次，快速切换会取消旧请求。质量清单共用筛选，关键词和仅复核线索作为该清单的附加条件。
