# 前端基座验证记录

验证日期：2026-10-03。环境：Windows、Node.js 24.12.0、npm 11.6.2。

## 命令

- `npm run dev`：Vite服务实际启动，地址 http://localhost:5173。
- `npm run build`：生产构建成功；ECharts依赖块存在体积提示，不影响构建。
- `npm run check`：14市州边界、42个Marker、12,000座模拟充电站、82,300个模拟充电桩、六类专题、七个市州模块一致性通过。
- `npm run format:check`：统一格式检查。

Codex受限Windows沙箱中的esbuild因读取工作区上级目录被拒绝；环境审批后运行成功。这是执行环境权限问题，未修改构建逻辑规避权限。

## 实际浏览器检查

- 1920×1080：首页完整可见，文档高度1080、宽度1920，无横向或纵向溢出。
- 1366×768：首页自然滚动，内容宽度小于视口，无横向溢出。
- 地图点击长沙进入`/city/430100`，展示对应指标和市州边界。
- Marker点击显示示例名称、充电类型、桩数量及模拟提示。
- 排名切换公共充电桩后显示21,600等对应值。
- 示例站点图层开关、缩放、重置和返回全省正常。
- 市州选择器搜索湘西并跳转；14个市州详情逐一打开，均展示七个统一分析模块。
- 切换可达性模块展示待接入状态。
- 六个全省专题逐一切换，标题和待接入结果状态正确。
- 无效市州展示未找到提示，无效专题进入404；热力图入口提示预留能力。

## 文案与布局调整

- 页头使用平台名称，移除英文装饰标签、口号介绍和重复专题入口。
- 首页采用连续指标栏、区域统计、中央地图、市州排名和两张统计图。
- 区域进度条按全省占比显示，保留展示分组说明。
- 专题页采用数据条件、结果图层选择和结果状态布局；切换结果不会生成分析数据。
- 市州页使用设施概况、统计明细和专题结果等业务名称。
- 本轮检查1920×1080、1366×768及1024×768尺寸；地图、排名和专题切换保留。
