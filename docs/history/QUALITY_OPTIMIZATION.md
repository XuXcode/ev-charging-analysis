## 实测结果

- 130项后端回归通过；仅现有Starlette/httpx弃用提示。11项前端测试覆盖范围切换、取消、过期响应、API异常、URL、数值精度、CSV与摘要。
- npm run build通过，ECharts共享块653.24KB，gzip220.61KB，保留体积提示。路由、站点地图与质量抽屉独立分块，没有通过调高告警阈值隐藏问题。
- 七菜单1920×1080与1366×768的阶段性布局实测与截图见THEMATIC_LAYOUTS.md；最新浏览器默认1280×720复测参数错误、空范围、缺失快照、质量搜索/证据、导出和站点选中。最后再次调整浏览器尺寸时自动化控制超时，因此没有把最新默认尺寸截图标为1920或1366。
- 全省排名进入长沙，选择芙蓉区179条；Marker/聚合/热力与返回全省实测。最新站点信息窗显示来源、采集时间、GCJ-02、分类、复核状态、批次和检索上限警告。
- 切换密度/覆盖时共享地图和图表标题、排名、单位、URL；真实采集批次筛选刷新保持。个人类20条、已确认类0条已与API核对。不存在的批次保持快照待接入，不使用全省10745条替代。
- 浏览器捕获的应用控制台error日志为空。参数错误由页面明确显示并恢复；缺失快照404为预期数据状态。
- PNG实际保存并检查14市州图表及湖南省地图；14行市州CSV逐行核对真实数值、单位、编码、快照与8个市州完整性警告；122行区县清单逐行核对未覆盖面积、快照及17个警告，不生成风险等级。

## 性能与数据约束

本机三次HTTP中位耗时：市州200条站点60.35ms、bbox50.86ms、质量分页30.52ms、分析快照190.10ms、网格220.44ms。网格原始JSON约3.16MB，gzip约412KB；按图层与行政范围加载。现有索引下SQL市州1.45ms、区县0.87ms、bbox0.90ms、分类0.53ms、状态1.90ms、日期3.54ms、排名5.83ms，没有引入Redis的明确瓶颈证据。这是本机10745条样本的检查，不是生产并发容量承诺。

10745条仅为高德可检索POI样本；677条复核线索不等于无效设施；17区县检索上限不代表只有这些区县不完整。名称与原始类别不能确认实际营业、公共开放、车辆类型和桩数。1km直线几何覆盖使用米制近似，不代表道路可达性或人口覆盖。当前供需、分钟可达性和优化方案仍待接入。
